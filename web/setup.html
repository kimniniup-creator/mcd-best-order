    Token 是麦当劳发给你个人的一串字符，有了它我们才能替你查菜单、算价格、下单。

    1. 打开 open.mcd.cn 的 MCP 页面，用手机号和验证码登录
    2. 点 激活，页面会出现你的 Token
    3. 点 复制
    打开 open.mcd.cn ↗新窗口打开，弄好再回到这页

Token 只存在这台电脑上。存进系统自带的凭据管理器（Mac 是钥匙串），不写进日志或对话记录；系统钥匙串不可用时，会按本机支持情况提示。我们不经手钱，付款永远在麦当劳官方页面完成。想停用，去 open.mcd.cn 重新生成即可让旧的作废。
